## Главные выводы

1. **C# — строго типизированный язык.** Тип переменной указывается явно (или выводится компилятором через `var`, но фиксируется один раз). Это позволяет находить ошибки ещё на этапе компиляции, до запуска программы.

2. **Платформа .NET обеспечивает кроссплатформенность.** Исходный код компилируется в промежуточный **IL-код**, который затем выполняется средой **CLR** на любой ОС (Windows, macOS, Linux) с помощью **JIT-компиляции**. Один и тот же IL-код работает везде, где есть CLR.

3. **Git — обязательный инструмент современного разработчика.** Система контроля версий позволяет отслеживать изменения, возвращаться к предыдущим версиям, работать в команде и хранить проект как локально, так и в удалённом репозитории на GitHub.

4. **Терминал — основной инструмент управления проектом.** Создание проекта (`dotnet new`), сборка (`dotnet build`), запуск (`dotnet run`) и работа с Git выполняются через команды, что ускоряет разработку и не зависит от графического интерфейса.

## Ответы на вопросы

### 1. Чем `Console.Write()` отличается от `Console.WriteLine()`?

`Console.Write()` выводит текст **без** перехода на новую строку — следующий вывод продолжится на той же строке. `Console.WriteLine()` выводит текст **с** переходом на новую строку — курсор перемещается в начало следующей строки.

### 2. Что произойдёт, если попытаться присвоить переменной типа `int` значение `3.14`?

Компилятор выдаст **ошибку компиляции**: нельзя неявно преобразовать `double` в `int`, потому что это привело бы к потере дробной части. C# не выполняет такие преобразования автоматически.

### 3. Почему `10 / 3` в C# даёт `3`, а не `3.333...`? Как получить дробный результат?

Потому что оба операнда — целые числа (`int`). В C# при делении целых чисел выполняется **целочисленное деление**: дробная часть отбрасывается, результатом всегда является целое число.

### 4. Что означает `var` в C#? Чем он отличается от динамической типизации в Python?

`var` — это **неявная типизация**: компилятор сам определяет тип переменной по значению в момент объявления. Но тип **фиксируется один раз** и больше не меняется.

**Отличие от Python:**
- В Python переменная **динамическая** — её тип может меняться в любой момент: `x = 5`, потом `x = "текст"` — это нормально.
- В C# с `var` тип определяется **один раз при объявлении** и остаётся неизменным на всю жизнь переменной. `var` — это просто синтаксический сахар, чтобы не писать тип вручную; он **не делает** язык динамическим.
